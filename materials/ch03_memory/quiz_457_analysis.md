## 第1题：SRAM和DRAM的工作原理及优劣势

**原题**：简述SRAM和DRAM的工作原理，并分别分析他们的优劣势。

### 参考答案要点

| 对比项 | SRAM | DRAM |
|--------|:----:|:----:|
| 存储单元 | 触发器（6个晶体管） | 电容（1个晶体管+1个电容） |
| 工作原理 | 双稳态触发器锁存状态 | 电容充电/放电表示0/1 |
| 是否需刷新 | 不需要 | 需要（约每2ms刷新一次） |
| 速度 | 快 | 较慢 |
| 集成度 | 低 | 高 |
| 功耗 | 较大 | 较小 |
| 价格 | 高 | 低 |
| 用途 | Cache、寄存器 | 主存 |

### 记忆口诀
> **SRAM**：S = Speed（快），但贵、集成度低
> **DRAM**：D = Density（密度高），但慢、需刷新

## 第2题：扩展操作码设计

**原题**：某计算机指令字24位，定长格式，指令类型有双操作数指令、单操作数指令和无操作数指令，每个操作数地址字段均用8位表示，采用扩展操作码。若该指令系统已设计出M条双操作数指令，N条无操作数指令（0<M<2⁸，0<N<2¹⁶），那么最多还可设计出多少条单操作数指令？

### 解题思路

1. **指令格式分析**：24位定长指令
   - 双操作数：操作码 + 操作数A(8位) + 操作数B(8位) → 操作码占 24-16=8位
   - 单操作数：操作码 + 操作数(8位) → 操作码占 24-8=16位
   - 无操作数：操作码占 24位

2. **扩展操作码原理**：操作码从短到长扩展
   - 双操作数操作码占8位，可编码 2⁸=256 条，已用 M 条
   - 剩余 (256-M) 个编码用于扩展为单操作数指令
   - 每个双操作数剩余码点可扩展出 2⁸=256 条单操作数指令
   - 单操作数最多可设计 (256-M) × 256 条
   - 再用其中一部分扩展为无操作数指令
   - 每用掉一个单操作数编码，可扩展出 2⁸=256 条无操作数指令
   - 已设计 N 条无操作数指令，需要占用 ⌈N/256⌉ 个单操作数编码

3. **公式**：
   ```
   最多单操作数指令 = (2⁸ - M) × 2⁸ - ⌈N/2⁸⌉
                    = (256 - M) × 256 - ⌈N/256⌉
   ```

### 常见错误
- ❌ 忘记无操作数指令也要占单操作数的扩展空间
- ❌ 混淆8位和16位编码空间

## 第3题：6264芯片与8086芯片连接

**原题**：现需要将多片6264芯片接入8086芯片作为系统内存，要求其目标内存范围为0x70000H~0x77FFFH，请画出连接图。

### 解题要点

1. **芯片分析**：
   - 6264 SRAM 芯片：8K×8位
   - 每片容量 = 8KB = 2¹³B
   - 地址线：13根（A0~A12）
   - 8086：16位数据总线

2. **容量计算**：
   - 目标范围：0x70000H ~ 0x77FFFH
   - 总容量 = 0x8000H = 32KB
   - 需要 6264 芯片数量 = 32KB/8KB = 4片

3. **地址译码**：
   - 8086有20位地址线（A0~A19）
   - 每片6264占用13位（A0~A12）
   - 高位地址（A13~A19）用于片选译码
   - 范围 0x70000H~0x77FFFH：
     - A19 A18 A17 A16 A15 A14 A13
     - 0111 0000 0000 0... ~ 0111 0111 1111 1...
     - 高位固定：A19=0, A18=1, A17=1, A16=1
     - 通过译码器（如138译码器）产生4个片选信号

## 第5题：统计负数个数（编程题）

**原题**：内存按字节编址，从50000H单元开始顺序8K个单元存放着8位补码表示的定点纯整数。编程序统计该8K数据中负数的个数，并放在BX中。

### 解题思路
```
MOV  AX, 5000H     ; 设置段地址
MOV  DS, AX        
XOR  BX, BX        ; BX清零，用于计负数个数
MOV  CX, 2000H     ; 8K = 2000H，循环计数
MOV  SI, 0         ; 偏移地址从0开始

LOOP_START:
  MOV  AL, [SI]    ; 取一个数
  TEST AL, 80H     ; 测试最高位（符号位）
  JZ   NEXT        ; 非负则跳转
  INC  BX          ; 负数，BX加1

NEXT:
  INC  SI
  LOOP LOOP_START
```
