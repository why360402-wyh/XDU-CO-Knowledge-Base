# 演化层（evolvement）

## 这是什么？

这是四层架构中的**第4层——演化层**。存的是**你个人的、主观的、非教材的内容**。

## 什么时候往这里写东西？

| 场景 | 例子 | 你应该怎么做 |
|:-----|:-----|:------------|
| 你发现一种很好记的理解方式 | "补码就是把负数加上2ⁿ" | 写进演化层 |
| 你总结了一个做题套路 | "扩展操作码题先画格式，再算编码空间" | 写进演化层 |
| 你踩了一个坑 | "MOV [BX], 1200H 默认传字，不是字节" | 写进演化层 |
| 你有一个自己的类比 | "Cache就像书桌桌面，主存像书架，硬盘像图书馆" | 写进演化层 |

## 和 knowledge_points 的区别

```
knowledge_points：教材说的 → 客观、准确、考试要考的
evolvement：      我觉得的 → 主观、好记、帮自己理解的
```

## 建议目录结构

```
evolvement/
├── README.md        ← 你正在看的这个
├── my_notes/        ← 你的课堂笔记
│   ├── ch3_memory_notes.md
│   ├── ch4_instruction_notes.md
│   └── ch5_cpu_notes.md
├── my_tricks/       ← 你总结的解题技巧
│   ├── 扩展操作码速算法.md
│   └── 补码计算三步法.md
├── my_mistakes/     ← 你的错题本
│   └── 易错题汇总.md
└── my_analogies/    ← 你自己的类比和口诀
    └── 存储器层次类比.md
```

## 怎么写？

没有严格格式要求。这是**你的空间**，你想怎么写就怎么写。
唯一规则：**不要把你写的东西混入 knowledge_points**（那是教材的领地）。
