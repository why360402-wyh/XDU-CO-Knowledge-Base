# MOV指令与数据传送

## 1. MOV指令格式

```
MOV  DST, SRC    ; DST ← SRC（将源操作数的值复制到目的操作数）
```

### 1.1 操作数类型

| 操作数类型 | 示例 | 说明 |
|:---------:|:----|:-----|
| 立即数 | `1200H` | 常数，直接写在指令中 |
| 寄存器 | `AX`, `BX`, `CX`, `DX`, `SI`, `DI`, `BP`, `SP` | 16位寄存器 |
| | `AL`, `AH`, `BL`, `BH`, `CL`, `CH`, `DL`, `DH` | 8位寄存器 |
| 内存 | `[1200H]`, `[BX]`, `1100H[BX]` | 用[]括起来的地址 |

### 1.2 合法组合速查

```
MOV reg, reg     ✅ 寄存器→寄存器
MOV reg, imm     ✅ 立即数→寄存器
MOV reg, mem     ✅ 内存→寄存器
MOV mem, reg     ✅ 寄存器→内存
MOV mem, imm     ✅ 立即数→内存
MOV seg, reg     ✅ 寄存器→段寄存器
MOV reg, seg     ✅ 段寄存器→寄存器
MOV mem, seg     ✅ 段寄存器→内存

MOV mem, mem     ❌ 内存→内存（禁止！）
MOV seg, imm     ❌ 立即数→段寄存器（禁止！）
MOV seg, seg     ❌ 段寄存器→段寄存器（禁止！）
```

### 1.3 类型匹配规则

```
源和目的操作数类型必须一致：
- 要么都是8位（如 AL, BL, [1200H] 读取8位）
- 要么都是16位（如 AX, BX, [1200H] 读取16位）

MOV AL, 1200H    ❌ 8位寄存器←16位立即数
MOV AX, 12H      ✅ 16位寄存器←16位立即数（12H→0012H）

内存操作数的位数由另一操作数决定：
MOV [1200H], AL  → 写8位到1200H
MOV [1200H], AX  → 写16位到1200H和1201H
```

## 2. 小端存储（Little-Endian）⭐⭐⭐

8086/8088 采用**小端（Little-Endian）**方式存储多字节数据：

```
一个字（16位）存放在连续的两个字节中：
  低字节（低8位）→ 低地址
  高字节（高8位）→ 高地址

例如：AX=4C2AH，存入地址 21200H：
  (21200H) = 2AH（AL 的内容）
  (21201H) = 4CH（AH 的内容）

反过来，从21200H读一个字到AX：
  AL = (21200H) = 2AH
  AH = (21201H) = 4CH
  AX = 4C2AH
```

> ⚠️ **易错点**：很多人会把 AX 的高低位搞反！
> 记住口诀：**低地址放低字节，高地址放高字节**

## 3. 7种寻址方式的MOV示例对比

假设初始条件：
```
(DS)=2000H, (BX)=0100H, (SI)=0002H
(20100H)=12H, (20101H)=34H, (20102H)=56H, (20103H)=78H
(21200H)=2AH, (21201H)=4CH, (21202H)=B7H, (21203H)=65H
```

| 编号 | 指令 | 寻址方式 | EA/过程 | AX结果 |
|:----:|:----|:---------|:--------|:------:|
| ① | `MOV AX, 1200H` | 立即寻址 | AX ← 1200H | **1200H** |
| ② | `MOV AX, [1200H]` | 直接寻址 | EA=1200H, PA=21200H | **4C2AH** |
| ③ | `MOV AX, [BX]` | 寄存器间接 | EA=0100H, PA=20100H | **3412H** |
| ④ | `MOV AX, 1100H[BX]` | 基址寻址 | EA=1200H, PA=21200H | **4C2AH** |
| ⑤ | `MOV AX, [BX][SI]` | 基址加变址 | EA=0102H, PA=20102H | **7856H** |
| ⑥ | `MOV AX, 1100H[BX][SI]` | 基址加变址+位移 | EA=1202H, PA=21202H | **65B7H** |
| ⑦ | `LEA AX, 1100H[BX][SI]` | LEA取地址 | AX←EA=1202H | **1202H** |

**详细推导过程**：

```
① MOV AX, 1200H
  立即寻址，不访问内存，AX=1200H

② MOV AX, [1200H]
  EA = 1200H
  PA = DS×16 + EA = 20000H + 1200H = 21200H
  (21200H)=2AH → AL, (21201H)=4CH → AH
  AX = 4C2AH

③ MOV AX, [BX]
  EA = BX = 0100H
  PA = 20000H + 0100H = 20100H
  (20100H)=12H → AL, (20101H)=34H → AH
  AX = 3412H

④ MOV AX, 1100H[BX]
  EA = 1100H + 0100H = 1200H
  PA = 21200H（同②）
  AX = 4C2AH

⑤ MOV AX, [BX][SI]
  EA = BX + SI = 0100H + 0002H = 0102H
  PA = 20102H
  (20102H)=56H → AL, (20103H)=78H → AH
  AX = 7856H

⑥ MOV AX, 1100H[BX][SI]
  EA = 1100H + 0100H + 0002H = 1202H
  PA = 21202H
  (21202H)=B7H → AL, (21203H)=65H → AH
  AX = 65B7H

⑦ LEA AX, 1100H[BX][SI]
  注意！LEA不访问内存！
  AX = EA = 1100H + 0100H + 0002H = 1202H
```

## 4. MOV指令的微操作流程（补充理解）

> 这条指令在CPU内部是如何执行的？以 `MOV AX, [BX]` 为例：

```
取指阶段（对所有指令都相同）：
  T1: PC→MAR, Read=1
  T2: M(MAR)→MDR, PC+1→PC  
  T3: MDR→IR（指令译码）

执行阶段（MOV AX, [BX]）：
  T4: BX→MAR（将BX的值作为地址送MAR）
  T5: M(MAR)→MDR（从内存读出数据）
  T6: MDR→AX（将数据写入AX）
```

这体现了CPU执行一条MOV指令的完整过程——**并非"一步到位"**，而是分解为多个微操作。

## 5. 常见错误与陷阱

### 5.1 最常见错误TOP3

| # | 错误 | 正确理解 |
|:-:|:-----|:---------|
| 1 | MOV直接写内存地址给寄存器时用 `MOV AX, 1200H` | `MOV AX, 1200H` 是立即数！要访存必须加`[]` |
| 2 | 小端序搞反：认为`(20100H)=12H`时`AX=1234H` | 实际上`AL=(20100H)=12H, AH=(20101H)=34H` → `AX=3412H` |
| 3 | 混淆 `MOV AX, [BX]` 和 `LEA AX, [BX]` | MOV取内容，LEA取地址 |

### 5.2 边界情况

```
; 段超越（Segment Override）：
MOV AX, ES:[1200H]  ; 使用ES段而不是默认的DS
MOV AX, SS:[BX]     ; 强制使用SS段

; 字节与字：
MOV AL, [BX]        ; 读8位（字节）
MOV AX, [BX]        ; 读16位（字）
```

## 6. 练习题

### 练1
```
已知：(DS)=3000H, (BX)=0500H, (SI)=0003H
(30500H)=ABH, (30501H)=CDH
(35003H)=11H, (35004H)=22H

求下列指令的AX结果：
① MOV AX, [0500H]
② MOV AX, [BX]
③ MOV AX, 5000H[BX][SI]
```

<details>
<summary>答案</summary>

① EA=0500H, PA=30500H, AX=CDABH
② EA=BX=0500H, PA=30500H, AX=CDABH（同①）
③ EA=5000H+0500H+0003H=5503H, PA=35503H
   (35503H)=11H→AL, (35504H)=22H→AH, AX=2211H
</details>

### 练2
判断对错：`MOV [BX], 1200H` 是否合法？

<details>
<summary>答案</summary>

合法！这是将立即数1200H写入了BX指向的内存单元。
MOV mem, imm 是允许的。
注意：写入字还是字节由指令决定——没有指定时默认为字（16位）。
等价于：`MOV WORD PTR [BX], 1200H`
</details>
