# 8086/8088 寻址方式

## 0. 预备知识：物理地址计算

```
物理地址 = 段基址 × 16 + 有效地址(EA)

段基址 = 段寄存器内容（16位）
段基址 × 16 = 段基址左移4位 = 20位物理地址高16位
EA = 有效地址（16位，由寻址方式决定）

示例：(DS)=2000H, EA=1200H
物理地址 = 2000H × 10H + 1200H = 20000H + 1200H = 21200H
```

### 默认段寄存器规则

| 寄存器 | 默认段 | 用途 |
|:------:|:------:|:------|
| BX | DS | 数据段基址寄存器 |
| BP | **SS** | 堆栈段基址寄存器（！注意是SS不是DS） |
| SI | DS | 源变址寄存器 |
| DI | DS | 目的变址寄存器 |
| SP | SS | 堆栈指针 |

> ⚠️ **BP的默认段是SS**，这是最容易被忽略的考点！

## 1. 七种寻址方式详解

### ① 立即寻址

操作数直接包含在指令中，紧跟在操作码之后。

```
MOV  AX, 1200H    ; AX ← 1200H
                  ; 1200H 是指令的一部分，不访问内存
```

| 特点 | 说明 |
|:----|:------|
| 执行速度 | **最快**（无需访问内存） |
| 用途 | 给寄存器赋初值、传递常数 |

---

### ② 寄存器寻址

操作数在CPU寄存器中。

```
MOV  AX, BX       ; AX ← BX（BX的内容送AX）
ADD  DX, CX       ; DX ← DX + CX
```

| 特点 | 说明 |
|:----|:------|
| 执行速度 | **很快**（在CPU内部，不访存） |
| 指令长度 | 短（只需操作码+寄存器编码） |

---

### ③ 直接寻址

有效地址 EA = 指令中给出的16位位移量。

```
MOV  AX, [1200H]  ; EA = 1200H
                  ; 物理地址 = DS×16 + 1200H
                  ; AX ← (物理地址处的字)
```

**计算示例**：
```
设(DS)=2000H
MOV AX, [1200H] 执行过程：
① EA = 1200H
② 物理地址 = 20000H + 1200H = 21200H
③ 从21200H读取一个字送AX
④ 若(21200H)=2AH, (21201H)=4CH → AX=4C2AH

注意：小端存放！
  (21200H)=2AH → AL（低字节）= 2AH
  (21201H)=4CH → AH（高字节）= 4CH
  AX = 4C2AH !!!
```

| 特点 | 说明 |
|:----|:------|
| 需访问内存 | ✅ 需要 |
| 指令长度（含地址） | 较长（3字节以上） |

---

### ④ 寄存器间接寻址

EA = 寄存器内容（BX/BP/SI/DI）。

```
MOV  AX, [BX]     ; EA = BX
                  ; 物理地址 = DS×16 + BX
MOV  AX, [BP]     ; EA = BP
                  ; 物理地址 = SS×16 + BP（！注意段）
```

**计算示例**：
```
设(DS)=2000H, (BX)=0100H
MOV AX, [BX]:
① EA = BX = 0100H
② 物理地址 = 20000H + 0100H = 20100H
③ 假设(20100H)=12H, (20101H)=34H
④ AX = 3412H
```

| 寄存器 | 默认段 | 物理地址公式 |
|:------:|:------:|:------------|
| BX | DS | DS×16 + BX |
| SI | DS | DS×16 + SI |
| DI | DS | DS×16 + DI |
| BP | SS | **SS×16 + BP** |

---

### ⑤ 基址寻址（寄存器相对寻址）

EA = 位移量 + BX/BP。

```
MOV  AX, 1100H[BX]  ; EA = 1100H + BX
                     ; 物理地址 = DS×16 + BX + 1100H
MOV  AX, [BX+1100H]  ; 与上等价，两种写法
```

**计算示例**：
```
设(DS)=2000H, (BX)=0100H
MOV AX, 1100H[BX]:
① EA = 1100H + 0100H = 1200H
② 物理地址 = 20000H + 1200H = 21200H
③ AX = (21200H)的字
```

---

### ⑥ 变址寻址

EA = 位移量 + SI/DI。

```
MOV  AX, 1100H[SI]  ; EA = 1100H + SI
                     ; 物理地址 = DS×16 + SI + 1100H
MOV  AX, [SI+1100H]  ; 等价写法
```

**用途**：数组元素访问、字符串操作

---

### ⑦ 基址加变址寻址

EA = BX/BP + SI/DI（+ 位移量）。

```
MOV  AX, [BX][SI]           ; EA = BX + SI
MOV  AX, 1100H[BX][SI]      ; EA = BX + SI + 1100H
MOV  AX, [BX+SI+1100H]      ; 等价写法
```

**计算示例**：
```
设(DS)=2000H, (BX)=0100H, (SI)=0002H
MOV AX, 1100H[BX][SI]:
① EA = 1100H + 0100H + 0002H = 1202H
② 物理地址 = 20000H + 1202H = 21202H
③ (21202H)=B7H, (21203H)=65H
④ AX = 65B7H
```

**用途**：二维数组访问、结构体成员访问

## 2. 寻址方式速查表

| 编号 | 寻址方式 | 有效地址 EA | 默认段 | 是否访存 | 汇编示例（8086） |
|:---:|:--------:|:-----------:|:------:|:--------:|:----------------:|
| ① | 立即寻址 | — | — | ❌ | `MOV AX, 1200H` |
| ② | 寄存器寻址 | — | — | ❌ | `MOV AX, BX` |
| ③ | 直接寻址 | 位移量 | DS | ✅ | `MOV AX, [1200H]` |
| ④ | 寄存器间接寻址 | (BX) | DS | ✅ | `MOV AX, [BX]` |
| | | (BP) | **SS** | ✅ | `MOV AX, [BP]` |
| | | (SI)/(DI) | DS | ✅ | `MOV AX, [SI]` |
| ⑤ | 基址寻址 | 位移+(BX/BP) | DS/**SS** | ✅ | `MOV AX, 1100H[BX]` |
| ⑥ | 变址寻址 | 位移+(SI/DI) | DS | ✅ | `MOV AX, 1100H[SI]` |
| ⑦ | 基址加变址 | BX/BP+SI/DI+位移 | DS/**SS** | ✅ | `MOV AX, [BX][SI]` |

---

## 3. 快速判断法则

```
看源操作数格式           → 寻址方式
  立即数（无[]）         → 立即寻址
  寄存器（无[]）         → 寄存器寻址
  [数字]                → 直接寻址
  [BX]/[BP]/[SI]/[DI]  → 寄存器间接寻址
  数字[BX/BP]           → 基址寻址
  数字[SI/DI]           → 变址寻址
  [BX+SI]/[BP+DI]/...  → 基址加变址
  数字[BX+SI]/...       → 基址加变址（带位移）
```

## 4. 寻址方式与机器码的对应（选学加分）

```
MOV AX, [1200H]     → A1 00 12（直接寻址）
MOV AX, [BX]        → 8B 07（寄存器间接）
MOV AX, 1100H[BX]   → 8B 87 00 11（基址）
MOV AX, [BX][SI]    → 8B 03（基址加变址）
MOV AX, 1100H[BX][SI] → 8B 83 00 11
```

## 5. 综合练习题（含详细解析）

### 练1：填写MOV指令的EA和物理地址

```
已知：(DS)=1000H, (BX)=0200H, (SI)=0005H
      (10200H)=34H, (10201H)=12H
      (12205H)=A0H, (12206H)=B0H

| 指令                     | EA      | 物理地址 | AX结果 |
|:------------------------|:--------:|:--------:|:------:|
| MOV AX, [0200H]         |          |          |        |
| MOV AX, [BX]            |          |          |        |
| MOV AX, 2000H[BX]       |          |          |        |
| MOV AX, [BX][SI]        |          |          |        |
| MOV AX, 2000H[BX][SI]   |          |          |        |
```

<details>
<summary>答案</summary>

| 指令 | EA | 物理地址 | AX结果 |
|:----|:--:|:--------:|:------:|
| MOV AX, [0200H] | 0200H | 10200H | 1234H |
| MOV AX, [BX] | 0200H | 10200H | 1234H |
| MOV AX, 2000H[BX] | 2200H | 12200H | (12200H)~(12201H) |
| MOV AX, [BX][SI] | 0205H | 10205H | (10205H)~(10206H) |
| MOV AX, 2000H[BX][SI] | 2205H | 12205H | B0A0H |
</details>

### 练2：判断下列指令是否正确

```
① MOV [BX], [SI]           （  ） 
② MOV AX, [BX+SI+1200H]    （  ）
③ MOV AX, 1200H            （  ）
④ MOV [1200H], 3400H       （  ）
⑤ MOV BX, [BP]            （  ）
```

<details>
<summary>答案</summary>

① ❌ 内存→内存禁止传送
② ✅ 基址加变址带位移
③ ✅ 立即寻址
④ ✅ 直接寻址，立即数→内存
⑤ ✅ 寄存器间接，但段为SS
</details>
