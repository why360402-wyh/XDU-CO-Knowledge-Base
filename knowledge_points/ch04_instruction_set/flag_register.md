# 标志寄存器与条件码

## 1. 8086/8088 标志寄存器

16位标志寄存器中有9个有效标志位：

### 状态标志（6个）

| 标志 | 名称 | 含义 |
|:----:|:----|:-----|
| CF | 进位标志 | 最高位有进位/借位时=1 |
| PF | 奇偶标志 | 结果低8位中1的个数为偶数时=1 |
| AF | 辅助进位标志 | 低4位有进位/借位时=1 |
| ZF | 零标志 | 结果为零时=1 |
| SF | 符号标志 | 结果为负时=1（即最高位=1） |
| OF | 溢出标志 | 补码运算结果溢出时=1 |

### 控制标志（3个）

| 标志 | 名称 | 含义 |
|:----:|:----|:-----|
| IF | 中断允许标志 | 为1时允许可屏蔽中断 |
| DF | 方向标志 | 为1时串操作地址递减 |
| TF | 单步标志 | 为1时CPU单步执行（调试用） |
