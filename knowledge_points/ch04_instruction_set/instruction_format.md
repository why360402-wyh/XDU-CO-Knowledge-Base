# 指令格式与扩展操作码

## 1. 指令格式基础

### 1.1 指令的组成

一条指令通常包含两部分：

```
| 操作码 (OP) | 地址码 (Addr) |
```

| 字段 | 功能 | 说明 |
|:----:|:----|:-----|
| 操作码 (OP) | 指定操作类型 | 如 MOV、ADD、SUB、JMP 等 |
| 地址码 | 指定操作数位置 | 可以是寄存器、内存地址或立即数 |

### 1.2 按操作数个数的分类

| 类型 | 格式 | 指令字长分配 | 汇编示例 |
|:----:|:----|:------------|:--------:|
| 三操作数 | OP \| A₁ \| A₂ \| A₃ | 操作码+3个地址 | `ADD R1, R2, R3` |
| 双操作数 | OP \| A₁ \| A₂ | 操作码+2个地址 | `MOV AX, BX` |
| 单操作数 | OP \| A₁ | 操作码+1个地址 | `INC CX`、`JMP ADDR` |
| 无操作数 | OP | 全为操作码 | `NOP`、`RET`、`CLC` |

---

## 2. 操作码编码方式

### 2.1 定长操作码

```
所有指令的操作码位数相同

| 操作码（固定n位） | 地址码 |
```

**优缺点**：
| 优势 | 劣势 |
|:----|:-----|
| 译码简单（统一译码） | 编码空间利用率低 |
| 执行速度快（无需逐级译码） | 指令条数受限于2ⁿ |
| 硬件实现简单 | 短指令浪费操作码位数 |

**适用场景**：RISC 架构（如 ARM、MIPS）

### 2.2 变长操作码（扩展操作码）⭐⭐⭐⭐⭐

```
操作码的位数随指令类型而变化

双操作数: | 操作码(短) | 地址1 | 地址2 |
单操作数: | 操作码(中) | 地址  |
无操作数: | 操作码(长) |
```

**核心思想**：短操作码用完剩余编码 → 向地址码字段扩展成为更长操作码

**优缺点**：
| 优势 | 劣势 |
|:----|:-----|
| 编码空间利用率高 | 译码复杂（需要逐级判断） |
| 支持更多指令种类 | 速度略慢 |
| 灵活性强 | |

**适用场景**：CISC 架构（如 x86）

## 3. 扩展操作码 — 完整解题体系 ⭐⭐⭐⭐⭐

### 3.1 基本模型

假设：
- 指令字长 = L 位
- 双操作数指令：两个地址各需 n 位
- 单操作数指令：一个地址需 n 位
- 无操作数指令：无地址

**格式划分**：
```
双操作数: | OP(L-2n位) | Addr₁(n位) | Addr₂(n位) |
单操作数: | OP(L-n位)  | Addr(n位) |
无操作数: | OP(L位) |
```

### 3.2 核心公式推导

```
① 短操作码（双操作数）编码空间：
   OP数 = 2^(L-2n)
   已用 M 条，剩余 = 2^(L-2n) - M

② 扩展为单操作数：
   每个剩余短操作码可扩展出 2^n 个单操作数编码
   单操作数总编码空间 = (2^(L-2n) - M) × 2^n
   但需预留部分给无操作数扩展，设预留 R 个单操作数编码

③ 扩展为无操作数：
   每个单操作数编码可扩展出 2^n 个无操作数
   最大无操作数 = R × 2^n

④ 若有 N 条无操作数，则占用 R = ⌈N/2^n⌉ 个单操作数编码

⑤ 最多还可设计的单操作数 = (2^(L-2n) - M) × 2^n - ⌈N/2^n⌉
```

### 3.3 通用简化公式

当地址码字段均为 n 位时：
```
双操作数码点 = 2^(L-2n)
剩余双操作数码点 = 2^(L-2n) - M
单操作数总空间 = 剩余双操作数码点 × 2^n
无操作数占用的单操作数码点 = ⌈N/2^n⌉
最大单操作数 = 单操作数总空间 - 无操作数占用的单操作数码点
```

### 3.4 例题详解

#### 例题1（随堂测验原题）

> 某计算机指令字24位，定长格式，指令类型有双操作数指令、单操作数指令和无操作数指令，每个操作数地址字段均用8位表示，采用扩展操作码。若该指令系统已设计出M条双操作数指令，N条无操作数指令（0<M<2⁸，0<N<2¹⁶），那么最多还可设计出多少条单操作数指令？


**Step 1：确定格式**
```
24位字长，地址字段8位
双操作数: | OP(8) | A₁(8) | A₂(8) |    8+8+8=24
单操作数: | OP(16) | A(8) |              16+8=24
无操作数: | OP(24) |                       24=24
```

**Step 2：计算编码空间**
```
双操作数OP=8位 → 2⁸=256个编码
已用M条，剩余 = (256-M) 个
```

**Step 3：扩展为单操作数**
```
每个剩余双操作数码点 → 2⁸=256个单操作数编码（从8位扩展到16位）
单操作数总空间 = (256-M) × 256
```

**Step 4：预留无操作数空间**
```
已有N条无操作数指令，每占用1个单操作数编码→可扩展256条无操作数
无操作数占用的单操作数编码 = ⌈N/256⌉

注意：N可能小于256，此时只需占用1个单操作数编码即可满足
     N>256时，每256条无操作数消耗1个单操作数编码
```

**Step 5：最终公式**
```
最大单操作数 = (256-M) × 256 - ⌈N/256⌉
```

#### 例题2（具体数值）

> 上题中若 M=10, N=64，求最多可设计多少条单操作数指令？

```
最大单操作数 = (256-10) × 256 - ⌈64/256⌉
             = 246 × 256 - 1
             = 62976 - 1
             = 62975 条
```

#### 例题3（不同参数）

> 指令字长16位，地址码各占4位，已设计8条双操作数指令和20条无操作数指令，求最多单操作数指令数。

```
双操作数: | OP(8) | A₁(4) | A₂(4) |    8+4+4=16
单操作数: | OP(12) | A(4) |              12+4=16
无操作数: | OP(16) |                       16

双操作数OP=8位 → 2⁸=256个编码，已用8，剩余248
单操作数总空间 = 248 × 2⁴ = 248 × 16 = 3968
无操作数占用 = ⌈20/16⌉ = ⌈1.25⌉ = 2
最多单操作数 = 3968 - 2 = 3966
```

> 如果单操作数也用完了全部剩余编码，无法扩展无操作数怎么办？

## 4. 扩展操作码的图形化理解

```
把编码空间想象成一棵树：

                      双操作数OP(8位)
                     /    ...    \
                    /              \
   编码 00H ~ (M-1)H       编码 MH ~ FFH
    （已有的M条）         （剩余256-M个，扩展用）
                              /          \
                   每个扩展为256个单操作数
                         /        \
              用作单操作数        扩展为无操作数
              （其中部分用于扩展无操作数）
                                    \
                             每1个→256条无操作数
```

## 5. 常见错误汇总

| ❌ 错误 | ✅ 正确 |
|:--------|:--------|
| 忘记"+1"（空操作编码） | 计算字段位数用 ⌈log₂(n+1)⌉ |
| 混淆双操作数OP位数和单操作数OP位数 | 双OP=L-2n，单OP=L-n |
| 忘记无操作数指令也要占用编码空间 | 无操作数是从单操作数的编码空间里扩展的 |
| 总编码数用 2^L 算 | 总编码数取决于最小层（双操作数OP的位数） |
| N÷2^n 不用向上取整 | 占用必须是整数个编码点，⌈N/2^n⌉ |
| 认为是所有N条无操作数占N个编码 | 是占 ⌈N/2^n⌉ 个编码，不是N个 |

## 6. 练习题

### 练1
某机指令字长16位，每个地址码占4位，采用扩展操作码技术。已设计出14条双操作数指令和45条无操作数指令。问：
(1) 最多还能设计多少条单操作数指令？
(2) 若将单操作数指令增加到500条，是否可行？

<details>
<summary>答案</summary>

(1) 双OP=16-4-4=8位，编码256个
   剩余双OP=256-14=242
   单操作数最大=(242-⌈45/16⌉)×16=(242-3)×16=239×16=3824条

(2) 如果单操作数要500条
   500÷16=31.25，占32个双OP码点
   剩余双OP=242-32=210
   无操作数=210×16...不对，这步要重新算
   预留无操作数：45条需⌈45/16⌉=3个单操作数码点
   如果单操作数500条，共需占用 500÷16 向上取整=32个双OP码点
   还需3个给无操作数，总共需 32+3=35个双OP码点
   剩余242>35，所以可行。
</details>

### 练2
某机指令字长32位，地址码各占8位。已设计出60条双操作数指令和300条无操作数指令，求最多单操作数指令数。

<details>
<summary>答案</summary>

双OP=32-8-8=16位，2¹⁶=65536个编码
剩余=65536-60=65476
单操作数总=65476×2⁸=65476×256=16,761,856
无操作数占用=⌈300/256⌉=2
最多单操作数=16,761,856-2=16,761,854条
</details>
