# 存储器的层次结构

## 1. 存储体系的三层结构

```
寄存器     ← 最快速、最小容量、最高成本
   ↓
Cache      ← SRAM实现
   ↓
主存(内存)  ← DRAM实现
   ↓
辅存(硬盘)  ← 磁/光/固态存储
```

## 2. 层次化的设计目标

- **速度**：接近最快存储器的速度
- **容量**：接近最大存储器的容量
- **价格**：接近最便宜存储器的价格

## 3. 程序局部性原理

| 局部性类型 | 含义 | 示例 |
|:---------:|:-----|:-----|
| **时间局部性** | 刚访问的数据可能立即再访问 | 循环体中的指令 |
| **空间局部性** | 刚访问的数据附近的数据可能被访问 | 数组顺序访问 |

> 局部性原理是 Cache 能够有效工作的理论基础。
