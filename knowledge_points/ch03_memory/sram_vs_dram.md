# SRAM vs DRAM

## 1. 存储单元结构对比

### 1.1 SRAM 存储单元（6管静态触发器）

```
        Vcc
         │
    ┌────┤ R₁
    │    │
  T₃┼┐  └──┐ T₄
    │ │     ││
    └─┤     ├┘
      │  Q  │  Q̄
  T₁┼─┤     ├─┼T₂
    │ │     │ │
     ─┴─   ─┴─
     GND   GND
```

**工作原理**：
- 利用双稳态触发器的两个稳定状态存储信息
- T₁导通、T₂截止 → Q=1, Q̄=0 → 存储"1"
- T₁截止、T₂导通 → Q=0, Q̄=1 → 存储"0"
- T₃、T₄是负载管
- 读操作：通过控制字线打开T₅、T₆，读出Q和Q̄的值
- 写操作：强制置位Q和Q̄

**关键特性**：
- 只要不断电，数据**永久保持**（静态，不需刷新）
- 每个存储单元**6个晶体管**（4个构成触发器，2个作为控制门）
- 现代工艺也有4管、8管等变体，但均远多于DRAM

### 1.2 DRAM 存储单元（1T1C）

```
   字线(Word Line)
      │
      ├── T₁ (MOS管)
      │    │
      │   ┌┴┐
      │   │ │ C (电容)
      │   └┬┘
      │    │
     GND  GND
```

**工作原理**：
- 电容充电（有电荷）= 存储"1"
- 电容放电（无电荷）= 存储"0"
- 读操作：字线选通T₁，电容上的电荷通过数据线读出
- 写操作：通过数据线强制充放电

**关键特性**：
- 每个存储单元**1个晶体管+1个电容**（集成度极高）
- 电容会漏电 → 需要**定时刷新**
- **读操作是破坏性的**（读出后电荷被泄放，必须重写）

## 2. 详细对比表

| 对比维度 | SRAM | DRAM |
|:--------:|:----:|:----:|
| **存储单元** | 双稳态触发器（6个晶体管） | 1个晶体管+1个电容（1T1C） |
| **是否需要刷新** | ❌ **不需要** | ✅ **需要**（约64ms刷新一次） |
| **是否破坏性读出** | ❌ 非破坏性 | ✅ 破坏性（读后需重写） |
| **访问速度** | **快**（1~10ns） | **较慢**（50~100ns） |
| **集成度** | 低（6管/位） | **极高**（1管/位） |
| **单位容量** | 小 | **大**（同面积大6倍以上） |
| **静态功耗** | 较大（始终有电流） | **小**（电容不耗电） |
| **动态功耗** | 低 | 较高（刷新耗电） |
| **价格/位** | **高** | **低**（1/6~1/10） |
| **易失性** | 易失（断电丢失） | 易失（断电丢失） |
| **主要用途** | Cache、寄存器 | 主存、显存 |

## 3. DRAM的刷新机制 ⭐

### 3.1 为什么需要刷新？
DRAM的电容存在漏电现象，电荷会逐渐流失。若不刷新，数据最多保持几毫秒就会丢失。

### 3.2 刷新周期
- 早期DRAM：每 **2ms** 刷新一次
- 现代DRAM：每 **64ms** 刷新一次
- 刷新按**行**进行，每次刷新一行

### 3.3 三种刷新方式

| 方式 | 做法 | 优点 | 缺点 |
|:----:|:----|:----|:----:|
| **集中刷新** | 在每2ms内集中一段时间刷新所有行 | 控制简单 | 刷新期间无法访问（死时间） |
| **分散刷新** | 在每个读写周期后刷新一行 | 均匀分布，无死时间 | 延长了每个存取周期 |
| **异步刷新** | 定时刷新，与CPU操作异步 | 效率高，广泛使用 | 控制略复杂 |

**计算公式**：
```
刷新间隔时间 = 刷新周期 ÷ 行数
例如：64ms刷新4096行 → 每15.6μs刷新一行
```

### 3.4 刷新相关考题
> 某DRAM芯片有4096行，要求64ms内刷新全部行，问每隔多长时间需要刷新一行？

```
刷新时间间隔 = 64ms ÷ 4096 = 15.625μs
```

## 4. SRAM vs DRAM 应用场景分析

### 4.1 为什么Cache用SRAM不用DRAM？

```
Cache的需求：速度极快（匹配CPU速度）
            容量较小（几MB~几十MB）
            持续通电（不需考虑断电保持）

SRAM的特性：速度极快（1~10ns）✅
            集成度低、容量小 ✅（Cache不需要大容量）
            价格贵（Cache容量小，成本可接受）✅
            不需刷新（使用简单）✅

结论：SRAM完全匹配Cache需求
```

### 4.2 为什么主存用DRAM不用SRAM？

```
主存的需求：容量大（几GB~几十GB）
            速度适当（能配合总线速度即可）
            成本低（主存容量大，单价敏感）

DRAM的特性：集成度高、容量大 ✅
            速度可接受（配合现代总线）✅
            价格便宜 ✅
            需刷新（用专用刷新电路解决）⚠️（可接受）

结论：DRAM满足主存的容量和成本要求
```

## 5. 常考题型与答题模板

### 题型1：简述SRAM和DRAM的工作原理，分析优劣势（Quiz Q1）

**答题模板**：

```
【SRAM】
工作原理：______（双稳态触发器、6个晶体管）
优势：______（速度快、不需刷新、控制简单）
劣势：______（集成度低、价格高、功耗大）

【DRAM】
工作原理：______（1T1C、电容充放电）
优势：______（集成度高、容量大、价格低）
劣势：______（需刷新、速度较慢、控制复杂）

【用途】
SRAM→Cache、DRAM→主存
```

### 题型2：为什么DRAM需要刷新？

**答题要点**：
1. 电容漏电的物理特性
2. 破坏性读出需要重写
3. 刷新周期（64ms）
4. 三种刷新方式的简要说明

### 题型3：SRAM和DRAM最本质的区别是什么？

**答案**：**存储单元的结构不同**。
SRAM用触发器（有源器件），DRAM用电容（无源器件）。
这导致了速度、集成度、是否需要刷新等一系列差异。

## 6. 速记口诀

```
SRAM——SuperRAM？
  六管触发器，快但贵，
  不用刷新，Cache内。

DRAM——Dynamic！
  一管一电容，大又便，
  要刷新，主存见。

SRAM：Speed（快）、Static（静态）、SRAM→Cache
DRAM：Density（密度高）、Dynamic（需刷新）、DRAM→主存
```
