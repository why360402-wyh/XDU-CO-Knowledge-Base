# 地址译码与片选

## 1. 地址译码的基本概念

地址译码 = 用高位地址线产生芯片的**片选信号**。

### 为什么需要地址译码？

```
CPU通过地址总线发出一个地址
→ 高位地址决定选哪个芯片（片选）
→ 低位地址决定选芯片内的哪个单元（片内寻址）
```

### 地址分配公式

```
总地址 = 片选地址(高位) + 片内地址(低位)
```

| 部分 | 作用 | 位数决定 |
|:----:|:----|:---------|
| 高位地址 | 选择芯片（片选CS） | 芯片数量 |
| 低位地址 | 选择芯片内单元 | 芯片容量（2ⁿ） |

---

## 2. 三种译码方式

### 2.1 全译码

所有高位地址线都参与译码。

```
A₁₉ A₁₈ A₁₇ ... A₁₃ A₁₂ ... A₀
↑── 全部参与译码 ──↑
```

**优点**：
- 地址唯一（每地址只对应一个存储单元）
- 无地址重叠

**缺点**：
- 译码电路复杂
- 不灵活（容量变化需改译码逻辑）

**推荐**：考试中默认使用全译码

### 2.2 部分译码

部分高位地址线未参与译码（悬空）。

```
A₁₉ A₁₈ A₁₇ ... A₁₃ A₁₂ ... A₀
↑── 参与译码 ──↑↑─ 未参与 ─↑
```

**优点**：译码电路简单
**缺点**：存在**地址重叠**（一个物理单元对应多个地址）

### 2.3 线选译码

每根高位地址线直接选通一个芯片（不用译码器）。

```
A₁₃ → 芯片1 CS
A₁₄ → 芯片2 CS
A₁₅ → 芯片3 CS
```

**优点**：电路最简单
**缺点**：地址不连续、浪费地址空间

## 3. 常用译码器芯片

### 74LS138（3-8译码器）

```
      ┌──────────┐
  A   ─┤1       15├── Y₀    G₁=1,G₂A=0,G₂B=0时工作
  B   ─┤2       14├── Y₁    选择CBA→对应Y输出低电平
  C   ─┤3       13├── Y₂    
  G₁  ─┤6       12├── Y₃    (G₁高有效)
  G₂A ─┤4       11├── Y₄    (G₂A低有效)
  G₂B ─┤5       10├── Y₅    (G₂B低有效)
       │         9├── Y₆
       │         7├── Y₇
       └──────────┘
```

### 74LS139（双2-4译码器）

```
每个封装内含两个独立的2-4译码器
适合只有2-3个芯片的场景
```

## 4. 完整例题：多种译码方案对比

> 要求：用8KB×8位芯片（如6264）构建16KB内存，起始地址00000H。

### 方案一：全译码（用138）

```
2片6264 = 16KB
每片需要13位地址 A₀~A₁₂
高位 A₁₃~A₁₉（7位）→ 138译码 → Y₀,Y₁分别选两片

第1片：00000H~01FFFH
第2片：02000H~03FFFH

高位 A₁₃~A₁₉ 取值：
A₁₃ A₁₄ A₁₅ A₁₆ A₁₇ A₁₈ A₁₉
  0   0   0   0   0   0   0  → 第1片(Y₀)
  1   0   0   0   0   0   0  → 第2片(Y₁)
```

### 方案二：线选译码

```
A₁₃直接选通第1片，A₁₄直接选通第2片：
第1片 CS ← A₁₃
第2片 CS ← A₁₄

这样 A₁₅~A₁₉ 未参与译码：
地址范围不唯一——第1片实际映射到：
  00000H~01FFFH（A₁₅~A₁₉全0时）
  08000H~09FFFH（A₁₅=1时）
  ...
  共2⁵=32个重叠区域
```

### 对比

| 方案 | 电路复杂度 | 地址重叠 | 推荐度 |
|:----:|:---------:|:--------:|:------:|
| 全译码 | 较复杂 | 无 | ⭐⭐⭐ |
| 部分译码 | 简单 | 有 | ⭐⭐ |
| 线选 | 最简单 | 严重 | ⭐ |

> 考试建议：**全译码**是最稳妥的选择。
