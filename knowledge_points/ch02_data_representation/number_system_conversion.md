## 2. 进制转换方法（完整版）

### 2.1 R进制 → 十进制（按权展开法）

**通用公式**：
```
(N)R = aₙ₋₁×Rⁿ⁻¹ + aₙ₋₂×Rⁿ⁻² + ... + a₁×R¹ + a₀×R⁰ + a₋₁×R⁻¹ + ...
```

**例题1**：`1011.01B` 转十进制
```
= 1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 0×2⁻¹ + 1×2⁻²
= 8 + 0 + 2 + 1 + 0 + 0.25
= 11.25
```

**例题2**：`2FH` 转十进制
```
= 2×16¹ + 15×16⁰
= 32 + 15
= 47
```

**例题3**：`137O` 转十进制
```
= 1×8² + 3×8¹ + 7×8⁰
= 64 + 24 + 7
= 95
```

---

### 2.2 十进制 → R进制

#### 整数部分：除基取余法
> **口诀**：除以基数取余数，从下往上读结果

**例题4**：十进制 `25` 转二进制

| 步骤 | 计算 | 商 | 余数 |
|:----:|:----:|:--:|:----:|
| 1 | 25÷2 | 12 | **1** ← 最低位(LSB) |
| 2 | 12÷2 | 6 | **0** |
| 3 | 6÷2 | 3 | **0** |
| 4 | 3÷2 | 1 | **1** |
| 5 | 1÷2 | 0 | **1** ← 最高位(MSB) |

**结果**：`25D = 11001B` ✓

**例题5**：十进制 `125` 转十六进制

| 步骤 | 计算 | 商 | 余数 |
|:----:|::----:|:--:|:----:|
| 1 | 125÷16 | 7 | **13 = D** |
| 2 | 7÷16 | 0 | **7** |

**结果**：`125D = 7DH` ✓

#### 小数部分：乘基取整法
> **口诀**：乘以基数取整数，从上往下读结果

**例题6**：`0.625D` 转二进制

| 步骤 | 计算 | 整数部分 |
|:----:|:----:|:--------:|
| 1 | 0.625×2 = 1.25 | **1** ← 最高位 |
| 2 | 0.25×2 = 0.5 | **0** |
| 3 | 0.5×2 = 1.0 | **1** ← 最低位 |

**结果**：`0.625D = 0.101B` ✓

**⚠️ 注意**：小数部分可能无限循环！
```
0.1D 转二进制：
0.1×2=0.2 → 0
0.2×2=0.4 → 0
0.4×2=0.8 → 0
0.8×2=1.6 → 1
0.6×2=1.2 → 1
0.2×2=0.4 → 0  (开始循环!)
...
0.1D = 0.0001100110011...B（无限循环小数）
```

### 2.3 二进制 ↔ 八进制/十六进制（分组法）

二进制转八进制**每3位一组**，转十六进制**每4位一组**。
> **原理**：2³=8，2⁴=16，所以3位二进制对应1位八进制，4位对应1位十六进制。

| 方向 | 方法 | 示例 |
|:----:|:----|:----|
| 二→八 | 小数点为界，向两边每3位一组，组内按权展开 | `1101011B → 001 101 011 → 153O` |
| 二→十六 | 小数点为界，向两边每4位一组，组内按权展开 | `1101011B → 0110 1011 → 6BH` |
| 八→二 | 每位数字转3位二进制 | `153O → 001 101 011 → 1101011B` |
| 十六→二 | 每位数字转4位二进制 | `6BH → 0110 1011 → 1101011B` |

**例题7**：`1010110.011B` 转八进制
```
二进制：001 010 110 . 011  （前补0凑3位）
八进制： 1   2   6  .  3
结果：126.3O
```

**例题8**：`1010110.011B` 转十六进制
```
二进制：0101 0110 . 0110  （后补0凑4位）
十六进制： 5    6   .  6
结果：56.6H
```

**规则**：逢二进一

**例题9**：`1011B + 0111B`
```
   1011
+  0111
--------
  10010
```

**例题10**：`1101B - 0110B`（借位法）
```
   1101
-  0110

   0111
```

## 5. 常考陷阱与易错点

| ❌ 常见错误 | ✅ 正确做法 |
|:-----------|:-----------|
| 十进制转二进制除2时，余数顺序搞反（从上往下读） | **从下往上读**（最后一个余数是最高位） |
| 小数转二进制乘2时，顺序搞反 | **从上往下读**（第一个整数是最高位） |
| 十六进制数以字母开头时忘记加前导0 | `FFH` × → `0FFH` ✓ |
| 二进制分组时方向搞反 | 从**小数点**向两边分，不是从最左边 |
| 混淆十进制和十六进制的 10~15 | A=10, B=11, C=12, D=13, E=14, F=15 |
| 小数部分转其他进制时忽略精度 | 有限十进制小数转二进制后可能是无限循环 |

## 6. 综合练习题（含详细解析）

### 练1：进制互转

将 `3FB.8H` 分别转为二进制和十进制。

<details>
<summary>点击查看解析</summary>

**转二进制**（每位十六进制转4位二进制）：
```
3   → 0011
F   → 1111
B   → 1011
8   → 1000
结果：0011 1111 1011 . 1000B = 1111111011.1B
```

**转十进制**（按权展开）：
```
= 3×16² + 15×16¹ + 11×16⁰ + 8×16⁻¹
= 3×256 + 15×16 + 11×1 + 8×0.0625
= 768 + 240 + 11 + 0.5
= 1019.5
```
</details>

### 练2：十进制转R进制

将 `0.2D` 转为二进制（保留到小数点后6位）。

<details>
<summary>点击查看解析</summary>

```
0.2×2=0.4 → 0
0.4×2=0.8 → 0
0.8×2=1.6 → 1
0.6×2=1.2 → 1
0.2×2=0.4 → 0  ← 开始循环！
...

结果：0.2D = 0.001100110011...B（无限循环）
保留6位：0.001101B
```
</details>

### 练3：二进制算术

计算 `101101B - 011011B`（用补码法）。

<details>
<summary>点击查看解析</summary>

**补码法做减法**：
```
101101B = 45D
011011B = 27D
期望结果 = 18D

011011B的补码 = 100101B（取反+1）
101101B + 100101B = 1010010B
去掉最高位进位 = 010010B = 18D ✓
```
</details>

### 练4：综合应用

某计算机内存按字节编址，地址范围为 `50000H ~ 51FFFH`，问这片内存空间的大小是多少KB？

<details>
<summary>点击查看解析</summary>

```
空间大小 = 51FFFH - 50000H + 1 = 2000H
2000H = 2×16³ = 2×4096 = 8192 = 8KB
```
</details>

### 练5：补码范围

8位补码所能表示的最小负数是什么？写出其二进制和十进制。

<details>
<summary>点击查看解析</summary>

```
n位补码最小值 = -2ⁿ⁻¹
8位补码最小值 = -2⁷ = -128
二进制 = 1000 0000B

验证：1000 0000 取反得 0111 1111，加1得 1000 0000
      所以 -128 的补码还是 1000 0000 ✓
```
</details>
