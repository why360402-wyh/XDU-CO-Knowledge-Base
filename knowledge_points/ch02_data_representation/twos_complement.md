# 补码表示（Two's Complement）

## 1. 定义

**补码**是计算机中最常用的带符号整数编码方式。其核心思想是：**将减法转化为加法**，从而简化硬件设计。

## 2. 求补码的规则

### 正数的补码 = 原码本身

### 负数的补码：

**方法一（标准法）**：
1. 写出该数的绝对值的二进制原码
2. 各位取反（得到反码）
3. 末位加 1

**方法二（快速法）**：
1. 从右向左找到第一个 `1`
2. 该 `1` 左边全部取反，右边不变

### 示例：求 -13 的 8 位补码

```
方法一：
  +13 的原码：0000 1101
  取反得反码：1111 0010
  末位加 1 ：1111 0011  ← -13的补码

方法二：
  +13 的原码：0000 1101
  从右数第一个1的位置：bit0的1
  左边取反：    1111 001
  右边不变：           1
  结果：       1111 0011
```

## 3. 补码的真值还原

若补码的**最高位为0**（正数）：直接按二进制转十进制
若补码的**最高位为1**（负数）：
1. 末位减 1
2. 各位取反
3. 转十进制，加负号

**或**：先减1再取反

### 示例：`1111 0011` 的十进制值
```
1111 0011 → 末位减1 → 1111 0010 → 取反 → 0000 1101 = 13 → -13
```

## 4. n位补码的表示范围

| 位数 | 最小值 | 最大值 | 个数 |
|:---:|:------:|:------:|:----:|
| n | -2ⁿ⁻¹ | 2ⁿ⁻¹-1 | 2ⁿ |
| 8 | -128 | 127 | 256 |
| 16 | -32768 | 32767 | 65536 |

> ⚠️ **特殊记忆**：补码比原码多表示一个最小负数（如8位补码有-128，原码没有）

## 5. 补码的运算优势

- **减法变加法**：A - B = A + (-B的补码)
- **符号位参与运算**：无需单独处理符号位
- **溢出可检测**：双进位法判断

### 补码加减法示例
```
  0000 1101  (+13)
+ 1111 0011  (-13)
-----------------
  0000 0000  (进位1被自然丢弃，结果为0) ✓
```

## 6. 补码的扩展

- **符号扩展**：高位用符号位填充
  - 正数补0：`0111` → `0000 0111`
  - 负数补1：`1111 0011` → `1111 1111 1111 0011`

## 7. 常见错误

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 认为补码的符号位不能参与运算 | 符号位参与运算，进位自然丢弃 |
| 混淆n位补码的最小值和最大值 | 负的绝对值比正的大1 |
| 符号扩展时只补0 | 负数必须补1 |
