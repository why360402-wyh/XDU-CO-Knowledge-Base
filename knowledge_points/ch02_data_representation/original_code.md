# 原码表示

## 1. 定义

原码是最直观的带符号数编码方式：**最高位为符号位（0正1负），其余位为数值的绝对值**。

## 2. 格式

```
n位原码：符号位(1位) + 数值位(n-1位)
```

**示例（8位原码）**：
```
+13 = 0000 1101
     ↑
     符号位=0(正)

-13 = 1000 1101
     ↑
     符号位=1(负)
```

## 3. n位原码的表示范围

| 位数 | 范围 |
|:---:|:----:|
| n | [-(2ⁿ⁻¹-1), +(2ⁿ⁻¹-1)] |
| 8 | [-127, +127] |
| 16 | [-32767, +32767] |

> ⚠️ **注意**：原码中有两个0—— `+0=0000 0000` 和 `-0=1000 0000`

## 4. 原码的缺点

1. **加减运算复杂**：符号位不能直接参与运算，需要先判断符号再决定做加法还是减法
2. **有两个0**：浪费了一个编码
3. **加减法硬件设计复杂**：需要单独的处理逻辑

> 因此计算机内部实际使用**补码**存储整数，原码主要用于理解概念和浮点数尾数表示。
