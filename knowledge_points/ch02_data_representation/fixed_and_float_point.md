# 定点数与浮点数

## 1. 定点数 (Fixed-Point Number)

小数点位置固定不变的数。

### 定点整数
- 小数点固定在最低位之后
- `n`位定点整数范围（补码）：[-2ⁿ⁻¹, 2ⁿ⁻¹-1]

### 定点小数
- 小数点固定在符号位之后、数值位之前
- 表示范围：（补码）[-1, 1-2⁻⁽ⁿ⁻¹⁾]

### 示例
```
定点整数：   符号位 | 数值位           .（隐含小数点）
定点小数：   符号位 .（隐含小数点）| 数值位
```

## 2. 浮点数 (Floating-Point Number)

### IEEE 754 标准格式

```
N = (-1)^S × M × 2^E

S: 符号位（0正1负）
M: 尾数（有效数字，常以原码/补码表示）
E: 阶码（指数，常以移码表示）
```

### 32位单精度浮点数

| 符号(S) | 阶码(E) | 尾数(M) |
|:-------:|:-------:|:--------:|
| 1位 | 8位 | 23位 |

### 64位双精度浮点数

| 符号(S) | 阶码(E) | 尾数(M) |
|:-------:|:-------:|:--------:|
| 1位 | 11位 | 52位 |

## 3. 常考要点

1. **规格化浮点数**：尾数最高位为1（提高精度）
2. **阶码用移码表示**：便于比较大小
3. **浮点加减运算步骤**：
   ① 对阶（小阶向大阶对齐）
   ② 尾数相加减
   ③ 规格化
   ④ 舍入处理
   ⑤ 判断溢出

## 4. 定点 vs 浮点对比

| 特性 | 定点数 | 浮点数 |
|------|:------:|:-------:|
| 表示范围 | 小 | 大 |
| 运算精度 | 高 | 相对较低 |
| 运算速度 | 快 | 慢 |
| 硬件复杂 | 简单 | 复杂 |
