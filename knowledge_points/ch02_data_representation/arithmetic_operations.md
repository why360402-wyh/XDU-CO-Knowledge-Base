# 机器数的加减运算

## 1. 补码加减法规则

### 加法
```
[X+Y]补 = [X]补 + [Y]补  (mod 2ⁿ)
```

### 减法
```
[X-Y]补 = [X]补 + [-Y]补  (mod 2ⁿ)
```

> 关键是求 `[-Y]补`：对 `[Y]补` **连同符号位取反加1**

## 2. 溢出判断（双进位法/双符号位法）

### 双进位法
```
若 C⊕C₀ = 1，则溢出
C  = 最高位的进位
C₀ = 次高位的进位
⊕  = 异或
```

### 双符号位法
```
用两位符号位 S₁S₂：
  S₁S₂ = 00 → 正数无溢出
  S₁S₂ = 11 → 负数无溢出
  S₁S₂ = 01 → 正溢出（结果>最大值）
  S₁S₂ = 10 → 负溢出（结果<最小值）
```

### 示例
```
8位补码：120 + 110 = 230 > 127（正溢出）
  0111 1000  (120)
+ 0110 1110  (110)
-----------------
  1110 0110  = -26（错误！原因是溢出）

C = 0, C₀ = 1, 0⊕1=1 → 溢出 ✓
```

## 3. 溢出的条件

| 条件 | 说明 |
|------|------|
| 正+正=负 | 正溢出 |
| 负+负=正 | 负溢出 |
| 正+负 | 永不溢出 |

## 4. 练习题

> 用8位补码计算 `-35 + (-60)`，判断是否溢出。
