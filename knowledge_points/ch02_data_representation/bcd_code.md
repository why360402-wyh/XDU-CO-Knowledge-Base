# BCD码 (Binary-Coded Decimal)

## 1. 定义

用4位二进制数表示1位十进制数。

## 2. 常用BCD码

### 8421 BCD码（最常用）

| 十进制 | 8421 BCD | 十进制 | 8421 BCD |
|:------:|:--------:|:------:|:--------:|
| 0 | 0000 | 5 | 0101 |
| 1 | 0001 | 6 | 0110 |
| 2 | 0010 | 7 | 0111 |
| 3 | 0011 | 8 | 1000 |
| 4 | 0100 | 9 | 1001 |

### 示例
```
十进制 29 → 8421 BCD：0010 1001
```

## 3. BCD码与二进制的区别

```
十进制 13
  二进制：     1101
  8421 BCD：  0001 0011
```

> ⚠️ BCD码中 1010~1111 是非法码

## 4. BCD码加法修正

```
BCD加法：若结果>1001(9)或产生进位，则加0110(6)修正

例：5 + 8 = 13
  0101 + 1000 = 1101（非法码，>9）
  1101 + 0110 = 0001 0011（进位+修正）= 13 ✓
```
