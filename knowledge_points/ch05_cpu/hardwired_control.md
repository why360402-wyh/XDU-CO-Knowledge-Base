# 硬布线控制器

## 1. 基本概念

硬布线控制器使用**组合逻辑电路**（门电路、触发器等）直接产生控制信号。

## 2. 设计方法

```
输入（指令码、节拍、状态标志）→ 组合逻辑网络 → 输出（微命令）
```

## 3. 优缺点

| 优势 | 劣势 |
|:----|:-----|
| 速度最快 | 设计复杂，不易修改 |
| 适合RISC | 规整性差 |
| 适合流水线 | 指令增加时电路复杂度剧增 |

## 4. 微程序 vs 硬布线 选择

| 场景 | 推荐方案 |
|:----|:---------|
| 复杂指令（CISC） | 微程序控制器 |
| 简单指令（RISC） | 硬布线控制器 |
| 要求高性能 | 硬布线控制器 |
| 要求灵活性/可扩展 | 微程序控制器 |
