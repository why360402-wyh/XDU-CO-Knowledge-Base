# 数据通路与微操作流程

## 1. 什么是数据通路？

数据通路是CPU内部各功能部件（寄存器、ALU、总线等）之间传输数据的路径和方式。

**核心思想**：一条机器指令的执行 = 若干微操作的序列 = 数据在通路中有序流动

---

## 2. 典型CPU数据通路模型

### 2.1 单总线结构

```
      ┌─────────────────────────────────────────┐
      │            内部总线 (16位)                 │
      └──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┘
         │  │  │  │  │  │  │  │  │  │  │  │  │
        MAR PC  IR  MDR A  B  C  ... ALU→FLAGS
                                      ↑
                                   控制信号
```

**特点**：
- 所有部件通过一组总线连接
- 同一时刻只能有一对部件进行数据传送
- 结构简单，但速度受限于总线

### 2.2 三总线结构（了解）

```
  总线A ────────┐
  总线B ────────┤  
  总线C ────────┤
                ALU→寄存器
```

**特点**：
- 可同时传送多组数据
- 结构复杂
- 速度更快

> 考试中通常使用**单总线模型**，理解一个就够了

### 2.3 各寄存器功能

| 寄存器 | 全称 | 功能 |
|:------:|:----|:-----|
| **PC** | 程序计数器 | 存放下一条指令的地址，取指后自动+1 |
| **MAR** | 存储器地址寄存器 | 存放要访问的主存单元地址 |
| **MDR** | 存储器数据寄存器 | 存放从主存读出/要写入主存的数据 |
| **IR** | 指令寄存器 | 存放当前正在执行的指令 |
| **A、B、C** | 通用寄存器 | 暂存操作数和中间结果 |
| **ALU** | 算术逻辑单元 | 执行算术和逻辑运算，产生标志位 |

## 3. 通用取指微操作流程 ⭐⭐⭐⭐⭐

**所有机器指令的取指阶段是公共的**：

### 3.1 标准取指流程（每条指令都执行）

```
T1: PC → MAR           ; 将PC中的指令地址送MAR（准备取指令）
    Read = 1           ; 发出读命令

T2: M(MAR) → MDR       ; 从主存读出指令到MDR
    PC + 1 → PC        ; PC自增，指向下一条指令地址

T3: MDR → IR           ; 将指令从MDR送入IR（指令译码器开始译码）
```

> 如果指令长度超过1个字，需要多次取指（如Quiz Q7中的OR指令占2个字）

### 3.2 双字指令的取指流程

```
T1: PC → MAR, Read=1
T2: M(MAR) → MDR, PC+1→PC
T3: MDR → IR           ; 取指令第一字
T4: PC → MAR, Read=1   ; 取指令第二字
T5: M(MAR) → MDR, PC+1→PC
T6: MDR → B            ; 指令第二字（操作数地址）→ B寄存器
```

## 4. 执行阶段微操作 — 常见指令类型

### 4.1 寄存器→寄存器（如 MOV AX, BX）

```
T4: BX → BUS           ; BX内容送上内部总线
T5: BUS → AX           ; 数据写入AX
```

### 4.2 寄存器→内存（如 MOV [1200H], AX）

```
T4: 1200H → MAR        ; 将操作数地址送MAR
T5: AX → MDR           ; AX内容送MDR
T6: Write = 1          ; 发写命令，MDR→M(MAR)
```

### 4.3 内存→寄存器（如 MOV AX, [BX]）

```
T4: BX → MAR, Read=1
T5: M(MAR) → MDR
T6: MDR → AX
```

### 4.4 算术运算指令（如 ADD AX, BX）

```
T4: AX → A             ; AX送A寄存器
T5: BX → B             ; BX送B寄存器
T6: ALU_OP=ADD          ; ALU执行加法
    ALUout → AX         ; 结果→AX
    Flags ← 更新        ; 更新标志位
```

## 5. 综合例题：OR [1500H], AX ⭐⭐⭐⭐⭐

> **原题**：某CPU构成的计算机框图如下。其內部总线及內部寄存器均为16位；主存储器按16位编址。采用数据通路描述方式、控制信号描述方式或两者混合的描述方式，写出在该计算机上，指令 OR [1500H],AX 的取指令、指令执行的微操作流程。(假设该指令由二个16位的字构成，主存中占二个地址)

### 5.1 指令含义

```
OR [1500H], AX
  操作：将内存地址1500H处的字 与 AX的内容 按位或，结果写回内存1500H处
  即： (1500H) = (1500H) OR AX
```

### 5.2 格式分析

```
第一个字（指令）：| 操作码 | ... |
第二个字（地址）：| 1500H |       ← 操作数地址
```

### 5.3 完整微操作流程

#### 取指令阶段（所有指令公共部分，略有调整）

```
T1:  PC → MAR          ; 送指令地址
     Read = 1          ; 启动读主存

T2:  M(MAR) → MDR      ; 读出指令第一字
     PC + 1 → PC       ; PC自增

T3:  MDR → IR          ; 指令第一字送IR（译码：知道是OR指令）

T4:  PC → MAR          ; 指令占2个字！再取第二个字
     Read = 1

T5:  M(MAR) → MDR      ; 读出操作数地址（1500H）
     PC + 1 → PC

T6:  MDR → B           ; 将1500H暂存到B寄存器
```

#### 执行阶段

**方式一：数据通路描述**

```
T7:  B → MAR           ; 将操作数地址1500H送MAR
     Read = 1          ; 启动读，准备读[1500H]的内容

T8:  M(MAR) → MDR      ; 读出[1500H]中的数（第一个操作数）
     ALU_OP = PASS     ; 
     MDR → A           ; 第一个操作数→A寄存器

T9:  AX → B            ; AX的内容→B寄存器（第二个操作数）
     ALU_OP = OR       ; ALU执行OR运算
     ALUout → MDR      ; 结果→MDR

T10: Write = 1         ; 写使能
     MDR → M(MAR)      ; 结果写回[1500H]单元
```

**方式二：控制信号描述**

```
T7:  MAR←B, Read=1
T8:  Wait, MDR←M, A←MDR, ALU_OP=PASS
T9:  B←AX, ALU_OP=OR, MDR←ALUout, Flags更新
T10: Write=1
```

### 5.4 执行过程可视化

```
取指:
                    PC→MAR→[主存]→MDR→IR (指令字)
                    PC→MAR→[主存]→MDR→B (地址1500H)

执行:
  B→MAR→[主存]→MDR              第一操作数(来自内存1500H)
                                ↓A
  AX→B                          第二操作数(来自AX)
                                ↓B
                              ALU执行OR
                                ↓
                              MDR→写回[1500H]
```

## 6. 答题规范

### 6.1 两"必须"

```
1. 取指阶段必须写出
   即使题目只问执行阶段，也要先写出取指过程（或者指出来"取指阶段同前"）

2. 控制信号必须明确
   读操作要写 Read=1
   写操作要写 Write=1
   ALU操作要写 ALU_OP=XXX
```

### 6.2 常用控制信号速查

| 信号 | 说明 |
|:----|:------|
| Read=1 | 启动主存读 |
| Write=1 | 启动主存写 |
| PC+1→PC | PC自增 |
| ALU_OP=ADD/SUB/AND/OR/XOR/PASS | ALU操作类型 |
| BUS←REG | 寄存器→总线 |
| REG←BUS | 总线→寄存器 |
| Flags更新 | 更新状态标志 |

### 6.3 常用的微操作速查表

```
PC → MAR  送指令地址
M(MAR) → MDR  从主存读取
MDR → M(MAR)  写入主存
MDR → IR  指令译码
PC + 1 → PC  地址增量
REG₁ → BUS → REG₂  寄存器间传送
REG → MAR  送操作数地址
REG₁ → A, REG₂ → B  ALU输入
ALUout → REG  ALU结果
```

## 7. 练习题

### 练1
写出指令 `ADD [2000H], CX` 的微操作流程（假设单字指令，主存按字编址）。

<details>
<summary>答案</summary>

取指：
T1: PC→MAR, Read=1
T2: M(MAR)→MDR, PC+1→PC
T3: MDR→IR

执行：
T4: 2000H→MAR, Read=1
T5: M(MAR)→MDR
T6: MDR→A, CX→B, ALU_OP=ADD
T7: ALUout→MDR
T8: Write=1, MDR→M(MAR)
</details>

### 练2
和 `ADD [2000H], CX` 相比，`ADD CX, [2000H]` 的微操作有什么不同？

<details>
<summary>答案</summary>

ADD [2000H], CX: 结果写回内存
  (2000H) = (2000H) + CX
  需要：读[2000H]→A，CX→B，结果→MDR→写回内存

ADD CX, [2000H]: 结果写回寄存器
  CX = CX + (2000H)  
  需要：读[2000H]→A，CX→B，结果→CX（不需写内存）
  
  T7: ALUout→CX （相比于上题的T7+T8，少了写内存的步骤）
</details>
