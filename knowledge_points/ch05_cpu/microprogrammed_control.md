# 微程序控制器原理

## 1. 基本概念

| 术语 | 定义 |
|:----|:-----|
| **微命令** | 控制部件向执行部件发出的基本控制信号 |
| **微操作** | 由微命令控制执行的最基本操作 |
| **微指令** | 一组同时发出的微命令的集合 |
| **微程序** | 由若干条微指令组成的序列（对应一条机器指令） |
| **控制存储器（CM）** | 存放微程序的只读存储器 |

## 2. 基本结构

```
机器指令 → 微地址形成电路 → 微地址寄存器(μAR)
                                    ↓
                             控制存储器(CM)
                                    ↓
                             微指令寄存器(μIR)
                              /            \
                     微命令字段          下地址字段
                          ↓                   ↓
                     执行部件          下地址逻辑
                                          ↓
                                     μAR（下一地址）
```

## 3. 微程序执行过程

```
① 取机器指令
   PC → MAR → 主存 → MDR → IR

② 微程序入口
   机器指令操作码 → 微地址形成电路 → 对应微程序首地址 → μAR

③ 逐条执行微指令
   μAR → CM → μIR
   微命令字段 → 控制各部件执行微操作
   下地址字段 → 送入μAR

④ 重复③直至该机器指令执行完毕
   回到①取下一条机器指令
```

## 4. 微程序设计思想

- 将每条机器指令分解为若干**微操作**
- 将同一时刻发出的微操作编码为**微指令**
- 一个机器指令对应一个**微程序**（若干微指令的序列）
- 微程序存放在**控制存储器**中

## 5. 微程序 vs 硬布线

| 对比 | 微程序控制器 | 硬布线控制器 |
|:----:|:-----------:|:------------:|
| 设计方法 | 微程序设计（软件思路） | 逻辑电路设计（硬件思路） |
| 灵活性 | 高（修改微程序即可） | 低（需修改电路） |
| 速度 | 较慢（读微指令需时间） | 快 |
| 成本 | 较低（规整） | 较高（复杂） |
| 适用场景 | CISC（复杂指令集） | RISC（精简指令集） |
