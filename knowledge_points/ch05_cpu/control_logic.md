# 触发逻辑与时序控制

## 1. 微操作的触发条件

在微程序控制器中，每个微操作的执行由**指令、节拍、条件**三要素控制：

```
微操作 = f(指令, 节拍, 条件)
```

通用表达式：

```
微操作_名称 = 指令_条件 × 节拍_条件 × 其他_条件
```

其中：
- 乘法表示逻辑**与**（AND）
- 加法表示逻辑**或**（OR）

---

## 2. 时序系统

### 2.1 三个层次

```
机器周期（指令周期）→ 节拍（状态T）→ 脉冲
```

| 时序层次 | 含义 |
|:--------:|:------|
| **指令周期** | 从取指令到执行完一条指令的时间 |
| **机器周期** | 访问一次主存的时间（读或写一个字） |
| **节拍**（T） | 最小的时序单元，一个时钟周期内完成一个微操作 |
| **脉冲** | 触发沿，微操作在脉冲有效时执行 |

### 2.2 典型时序

```
        ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐
CLK ────┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──
        T₁   T₂   T₃   T₄   T₅   T₆   ...

取指阶段 → |← 执行阶段 →|
           |← 指令周期 →|
```

## 3. 经典题型：触发逻辑表达式 ⭐⭐⭐⭐⭐

### 3.1 题型背景

> 题目通常会给出一个**微操作表**，形如：

| 节拍 | 指令1 (ADD) | 指令2 (SUB) | 指令3 (MOV) | ... |
|:----:|:-----------:|:-----------:|:-----------:|:---:|
| T1 | PC→MAR | PC→MAR | PC→MAR | ... |
| T2 | M(MAR)→MDR | M(MAR)→MDR | M(MAR)→MDR | ... |
| | PC+1→PC | PC+1→PC | PC+1→PC | ... |
| T3 | MDR→IR | MDR→IR | MDR→IR | ... |
| ... | | | | |

观察表中**哪些微操作在哪些节拍出现**，然后写出触发逻辑表达式。

### 3.2 原题（Quiz Q8）

> 某计算机指令对应的微操作表如下所示，根据表可知 I→IND 的触发逻辑为：
> `I→IND = FE·T2·(ADD + SAT + LDA + JMP + BAN)`
> 请参照该形式，写出 `M(MAR)→MDR` 的触发逻辑表达式。

### 3.3 解题方法

**Step 1：理解表达式**
```
I→IND = FE·T2·(ADD + SAT + LDA + JMP + BAN)
          ↑    ↑    ↑
       公共条件 节拍  需要这个微操作的指令集合

含义：在T2节拍，且当前指令是ADD/SAT/LDA/JMP/BAN中的任意一条，
      且FE条件满足时，触发I→IND微操作。
```

**Step 2：分析 M(MAR)→MDR 的出现情况**

`M(MAR)→MDR` 的含义：从主存中读出一个字到MDR。

它出现在：
1. **取指令阶段**的每个指令 + T2/T5节拍
2. **执行阶段**中需要读内存的指令

**Step 3：写出表达式**

通用形式：
```
M(MAR)→MDR = 取指公共节拍 + 执行阶段需要读内存的指令集合
```

具体需要根据微操作表来填写。典型表达式：
```
M(MAR)→MDR = FE·T2·(所有指令之和) + 执行阶段条件
```

假设微操作表中 `M(MAR)→MDR` 出现在：
- 取指T2：所有指令都需要
- 执行T2中某些指令（如ADD、LDA等需要读操作数）

则：
```
M(MAR)→MDR = FE·T2·(ADD+SUB+MOV+...所有指令...) + EX·T2·(ADD+LDA+...)
```

其中 FE = Fetch Enable（取指阶段使能），EX = Execute Enable（执行阶段使能）

### 3.4 常见微操作的触发条件归纳

| 微操作 | 典型触发节拍 | 说明 |
|:-------|:-----------:|:------|
| **PC→MAR** | T1 | 取指阶段第一个操作 |
| **M(MAR)→MDR** | T2(取指), T? (执行读) | 读主存 |
| **PC+1→PC** | T2(取指) | 取指后PC增量 |
| **MDR→IR** | T3(取指) | 指令送入IR译码 |
| **MDR→REG** | T? (执行) | 读出的数据送寄存器 |
| **REG→MAR** | T? (执行) | 送操作数地址 |
| **REG→BUS→REG'** | T? (执行) | 寄存器间传送 |
| **ALUout→REG** | T? (执行) | ALU结果写寄存器 |
| **MDR→M(MAR)** | T? (执行写) | 写回主存 |

## 4. 综合例题

> 已知某计算机的微操作表中，`PC→MAR` 出现在所有指令的取指T1节拍，以及JMP指令执行阶段的T1节拍（JMP跳转需要更新PC并送MAR）。写出 `PC→MAR` 的触发逻辑表达式。

**解**：
```
PC→MAR = T1·(取指) + T1·JMP
       = T1·(FE) + T1·JMP
       = T1·(FE + JMP)
```

> 如果题目用 FE 表示取指阶段，EX 表示执行阶段，则：
> ```
> PC→MAR = T1·FE·(所有指令之和) + T1·EX·JMP
>        = T1·FE·(全指令) + T1·EX·JMP
> ```
> 其中 FE 通常只在多周期CPU中使用，表示取指阶段的使能信号。
