> 考试前5分钟翻一遍，防止低级失误。

## 一、数值转换速查

### 2ⁿ 速记

```
2¹⁰ = 1K    = 1024
2¹¹ = 2K    = 2048
2¹² = 4K    = 4096
2¹³ = 8K    = 8192  ← 6264容量
2¹⁴ = 16K   = 16384
2¹⁵ = 32K   = 32768
2¹⁶ = 64K   = 65536
2²⁰ = 1M    = 1,048,576  ← 8086寻址空间
```

### 常用十六进制 ↔ 十进制

```
0x7F  = 127     (8位补码最大正数)
0x80  = 128     (8位补码最小负数的绝对值, 实际值=-128)
0xFF  = 255
0x7FFF = 32767  (16位补码最大正数)
0x8000 = 32768  (16位绝对值)
0xFFFF = 65535
0x10000 = 65536
```

## 二、存储器相关速查

### 芯片容量公式

```
芯片地址线数 = log₂(芯片容量)
容量(KB) = 2^(地址线数) ÷ 1024

常用：
  A₀~A₉  (10根) → 1KB
  A₀~A₁₀ (11根) → 2KB
  A₀~A₁₂ (13根) → 8KB  (6264)
  A₀~A₁₃ (14根) → 16KB (27128)
  A₀~A₁₄ (15根) → 32KB (62256)
```

### 地址计算

```
容量 = 末地址 - 首地址 + 1
末地址 = 首地址 + 容量 - 1

示例：
  8KB 范围 = 2000H 个单元
  32KB 范围 = 8000H 个单元
```

### 译码快速判断

```
A₁₉ A₁₈ A₁₇ A₁₆ A₁₅ A₁₄ A₁₃ | A₁₂ ... A₀
 ↑─ 片选译码用（查高位固定值）─↑ | ↑─ 片内地址 ─↑
```

## 三、指令系统速查

### 物理地址公式

```
物理地址 = 段寄存器 × 16 + 有效地址(EA)
```

### 7种寻址方式

| 方式 | EA公式 | 默认段 |
|:----|:-------|:------:|
| 立即 | — | — |
| 寄存器 | — | — |
| 直接 | 位移量 | DS |
| 寄存器间接 | (BX)/(SI)/(DI) | DS |
| | (BP) | **SS** |
| 基址 | 位移+(BX)/(BP) | DS/**SS** |
| 变址 | 位移+(SI)/(DI) | DS |
| 基址加变址 | BX/BP+SI/DI+位移 | DS/**SS** |

### 小端存储

```
低地址 ← 低字节(AL)
高地址 ← 高字节(AH)
例：AX=1234H → (addr)=34H, (addr+1)=12H
```

## 四、微程序设计速查

### 字段位数公式

```
某字段位数 = ⌈log₂(微命令数 + 1)⌉
条件位数 = ⌈log₂(条件数 + 1)⌉
下地址位数 = 总字长 - 微命令字段 - 条件字段
CM容量 = 2^(下地址位数) × 微指令字长
```

### 微操作书写规范

| 操作 | 写法 |
|:----|:-----|
| 取指令 | PC→MAR, Read=1 |
| 读内存 | M(MAR)→MDR |
| 写内存 | MDR→M(MAR), Write=1 |
| PC自增 | PC+1→PC |
| 寄存器传总线 | REG→BUS |
| 总线传寄存器 | BUS→REG |
| ALU运算 | ALU_OP=ADD/SUB/AND/OR |
| 结果写回 | ALUout→REG |

## 五、易错点检查清单

### 进制转换
- [ ] 除基取余是从**下往上**读
- [ ] 乘基取整是从**上往下**读
- [ ] 十六进制字母开头加前导0（`FFH`→`0FFH`）

### 补码
- [ ] 补码最小值是 -2ⁿ⁻¹（不是 -(2ⁿ⁻¹-1)）
- [ ] 正数补码 = 原码
- [ ] 负数补码 = 取反+1（不是取反减1）

### 存储器
- [ ] 所有高位地址都参与译码了吗？
- [ ] 芯片数量 = 总容量 ÷ 单芯片容量（向上取整）

### 寻址方式
- [ ] 区分 MOV（取内容）和 LEA（取地址）
- [ ] BP默认段是SS（不是DS）
- [ ] 小端序：低地址放低字节

### 微指令
- [ ] 每个字段+1算空操作了吗？
- [ ] 条件字段也是编码（需要+1）
- [ ] CM容量单位是字节还是位？
