> 数值转换是计组考试的基础题，几乎每次必考。
> 以下题目覆盖所有常见题型，建议先自己做，再对照解析。

## 一、进制互转（每题5分，共40分）

### 第1组：R进制 → 十进制

1. `101101B` = （   ）D
2. `3A.CH` = （   ）D
3. `137.4O` = （   ）D

<details>
<summary>答案</summary>

1. 101101B = 32+0+8+4+0+1 = **45D**
2. 3A.CH = 3×16 + 10 + 12/16 = 48+10+0.75 = **58.75D**
3. 137.4O = 1×64 + 3×8 + 7 + 4/8 = 64+24+7+0.5 = **95.5D**
</details>

### 第2组：十进制 → R进制

4. `89D` = （   ）B = （   ）H
5. `0.6875D` = （   ）B
6. `126D` = （   ）O

<details>
<summary>答案</summary>

4. 89D → 二进制：
   89÷2=44余1, 44÷2=22余0, 22÷2=11余0, 11÷2=5余1, 5÷2=2余1, 2÷2=1余0, 1÷2=0余1
   从下往上 = **1011001B**
   1011001B → 0101 1001 → **59H**

5. 0.6875×2=1.375→1, 0.375×2=0.75→0, 0.75×2=1.5→1, 0.5×2=1.0→1
   结果：**0.1011B**

6. 126÷8=15余6, 15÷8=1余7, 1÷8=0余1
   从下往上 = **176O**
</details>

### 第3组：二进制 ↔ 十六进制 互转

7. `101011110100.00110110B` = （   ）H
8. `F0C.8H` = （   ）B

<details>
<summary>答案</summary>

7. 1010 1111 0100 . 0011 0110 → **AF4.36H**
8. F→1111, 0→0000, C→1100, 8→1000 → **111100001100.1B**
</details>

## 二、原码/反码/补码（每题6分，共30分）

9. 写出 `+35` 的8位原码、反码、补码。
10. 写出 `-35` 的8位原码、反码、补码。
11. 8位补码 `11001010` 对应的真值是多少？
12. 已知 `[X]补 = F0H`（8位），求 `X`。
13. 求 `[-X]补`，已知 `[X]补 = 5BH`（8位）。

<details>
<summary>答案</summary>

9. +35 = 0010 0011
   原码：0010 0011
   反码：0010 0011（正数相同）
   补码：0010 0011（正数相同）

10. -35：
    原码：1010 0011
    反码：1101 1100
    补码：1101 1101

11. 1100 1010（补码）
    先减1：1100 1001
    取反：  0011 0110 = 32+16+4+2 = 54
    真值：-54

12. [X]补 = F0H = 1111 0000
    先减1：1110 1111
    取反：  0001 0000 = 16
    真值：-16

13. [X]补 = 5BH = 0101 1011
    [-X]补 = [X]补取反+1 = 1010 0100 + 1 = 1010 0101 = A5H
</details>

## 三、补码运算与溢出判断（每题6分，共30分）

14. 用8位补码计算 `58 + 85`，结果是否正确？
15. 用8位补码计算 `-64 + (-65)`，判断是否溢出。
16. 用8位补码计算 `120 + 15`，判断是否溢出。
17. 用8位补码计算 `-128 + (-1)`，判断是否溢出。
18. 已知 `[X]补 = 6AH`，`[Y]补 = 7BH`，求 `[X+Y]补` 并判断是否溢出。

<details>
<summary>答案</summary>

14. 58=00111010, 85=01010101
    00111010 + 01010101 = 10001111
    C=0, C₀=1, 溢出(正+正=负)，结果错误！
    实际上58+85=143>127，确实溢出。

15. -64补=11000000, -65补=10111111
    11000000 + 10111111 = 1 01111111
    C=1, C₀=0, 溢出(负+负=正)
    -64+(-65)=-129<-128，负溢出 ✓

16. 120补=01111000, 15补=00001111
    01111000 + 00001111 = 10000111
    C=0, C₀=1, 正溢出
    120+15=135>127，确实溢出 ✓

17. -128补=10000000, -1补=11111111
    10000000 + 11111111 = 1 01111111
    C=1, C₀=0, 负溢出
    -128+(-1)=-129<-128 ✓

18. [X]补=6AH=01101010, [Y]补=7BH=01111011
    01101010 + 01111011 = 11100101
    C=0, C₀=1, 正溢出！
    实际106+123=229>127 ✓
</details>

## 四、综合应用题（每题10分，共20分）

19. 某计算机按字节编址，内存地址范围为 `0A0000H ~ 0A3FFFH`。问：
    (1) 这片内存空间有多大？（用KB表示）
    (2) 如果用6264芯片（8KB/片）构成，需要几片？

20. 已知8位补码 `[X]补 = 10110101`，`[Y]补 = 01101101`。
    (1) 求 X 和 Y 的真值
    (2) 用补码计算 X+Y，判断是否溢出
    (3) 用补码计算 X-Y，判断是否溢出

<details>
<summary>答案</summary>

19. (1) 0A3FFFH - 0A0000H + 1 = 4000H = 16KB
    (2) 16KB ÷ 8KB = 2片

20. (1) [X]补=10110101
        减1: 10110100, 取反: 01001011 = 75
        X = -75
        [Y]补=01101101
        Y = +109（正数，直接转）
    
    (2) X+Y = -75+109 = 34
        10110101 + 01101101 = 1 00100010
        丢掉进位 = 00100010 = 34 ✓
        C=1, C₀=1, 1⊕1=0 无溢出 ✓
    
    (3) X-Y = -75-109 = -184 < -128
        先求[-Y]补: [Y]补取反+1 = 10010010+1 = 10010011
        10110101 + 10010011 = 1 01001000
        丢掉进位 = 01001000 = 72
        C=1, C₀=0, 1⊕0=1 负溢出！
        结果错误，因为-184超出8位补码范围
</details>
