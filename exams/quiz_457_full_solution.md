## 第1题：SRAM和DRAM（简答题）

**原题**：简述SRAM和DRAM的工作原理，并分别分析他们的优劣势。

### 参考答案

#### SRAM（静态随机存取存储器）

**工作原理**：
SRAM的每个存储单元由6个晶体管组成的双稳态触发器构成。通过触发器的两个稳定状态来存储0和1：Q=1,Q̄=0表示存储"1"，Q=0,Q̄=1表示存储"0"。只要不断电，状态就能永久保持，不需要刷新。

**优势**：
1. 速度快（访问时间1~10ns）
2. 不需要刷新电路，控制简单
3. 非破坏性读出

**劣势**：
1. 集成度低（6管/位），单位面积容量小
2. 价格昂贵
3. 静态功耗较大

#### DRAM（动态随机存取存储器）

**工作原理**：
DRAM的每个存储单元由1个晶体管和1个电容（1T1C）构成。通过电容的充放电来存储信息：电容充电（有电荷）表示"1"，放电（无电荷）表示"0"。由于电容会漏电，需要定时刷新（通常每64ms刷新一次）。

**优势**：
1. 集成度极高（1管/位），容量大
2. 价格便宜
3. 静态功耗小

**劣势**：
1. 速度较慢（50~100ns）
2. 需要刷新电路，控制复杂
3. 破坏性读出（读后需重写）

#### 应用
- SRAM：用于Cache、寄存器
- DRAM：用于主存

## 第2题：扩展操作码（计算题）

**原题**：某计算机指令字24位，定长格式，指令类型有双操作数指令、单操作数指令和无操作数指令，每个操作数地址字段均用8位表示，采用扩展操作码。若该指令系统已设计出M条双操作数指令，N条无操作数指令（0<M<2⁸，0<N<2¹⁶），那么最多还可设计出多少条单操作数指令？

### 解题过程

**Step 1：确定各指令的格式**

```
指令字长 = 24位，地址字段 = 8位

双操作数：| OP(24-8-8=8位) | A₁(8) | A₂(8) |
单操作数：| OP(24-8=16位)  | A(8)  |
无操作数：| OP(24位)       |
```

**Step 2：计算各层编码空间**

```
双操作数操作码8位 → 共有 2⁸ = 256 个编码
已用 M 条，剩余 256-M 个编码可以扩展
```

**Step 3：向单操作数扩展**

```
每个剩余的双操作数编码 → 向地址码字段扩展8位 → 2⁸ = 256个单操作数编码
单操作数总编码空间 = (256-M) × 256
```

**Step 4：向无操作数扩展**

```
无操作数指令从单操作数的编码空间中扩展
每使用1个单操作数编码 → 可扩展出 2⁸ = 256条无操作数
已设计 N 条无操作数 → 需要占用 ⌈N/256⌉ 个单操作数编码
```

**Step 5：最终公式**

```
最多单操作数指令 = (256-M) × 256 - ⌈N/256⌉
```

### 具体数值示例

若 M=10, N=64：
```
最多单操作数 = (256-10) × 256 - ⌈64/256⌉
             = 246 × 256 - 1
             = 62976 - 1
             = 62975 条
```

## 第3题：6264+8086连接（设计题）

**原题**：现需要将多片6264芯片接入8086芯片作为系统内存，要求其目标内存范围为0x70000H~0x77FFFH，请画出连接图。

### 解题过程

**Step 1：计算容量**
```
0x77FFFH - 0x70000H + 1 = 0x8000H = 32768 = 32KB
每片6264 = 8KB
需要片数 = 32 ÷ 8 = 4片
```

**Step 2：地址分配**
```
每片6264：8KB = 2¹³ → A₀~A₁₂（13根地址线，片内寻址）
8086：20位地址线 A₀~A₁₉

高位 A₁₃~A₁₉（7位）用于片选译码
```

**Step 3：地址范围分析**
```
0x70000H = 0111 0000 0000 0000 0000
0x77FFFH = 0111 0111 1111 1111 1111

A₁₉ A₁₈ A₁₇ A₁₆ A₁₅ A₁₄ A₁₃ | A₁₂~A₀
 0   1   1   1   0   0   0   | 片内 (第1片)
 0   1   1   1   0   0   1   | 片内 (第2片)
 0   1   1   1   0   1   0   | 片内 (第3片)
 0   1   1   1   0   1   1   | 片内 (第4片)

4个片选由 A₁₅ A₁₄ A₁₃ = 000, 001, 010, 011 区分
A₁₉=0, A₁₈=1, A₁₇=1, A₁₆=1 为固定值，用于译码器使能
```

**Step 4：译码电路**
```
方法：用 74LS138 译码器 + 门电路

A₁₉=0 通过非门 → 与非门输入1
A₁₈=1 → 与非门输入2
A₁₇=1 → 与非门输入3
A₁₆=1 → 与非门输入4
与非门输出 → G₁ (使能1)

G₂A=0, G₂B=0（接地）
A₁₅→C, A₁₄→B, A₁₃→A
Y₀→6264#1 CS₁, Y₁→6264#2 CS₁, Y₂→6264#3 CS₁, Y₃→6264#4 CS₁
各6264的CS₂接+5V，OE接读信号，WE接写信号
```

**Step 5：连接图（文字描述）**

```
8086地址总线 A₀~A₁₂ ──→ 4片6264的A₀~A₁₂（并行）
8086数据总线 D₀~D₇  ──→ 4片6264的D₀~D₇（并行）

片选逻辑：
  A₁₉·A₁₈·A₁₇·A₁₆ → 与非门 → 74LS138 G₁
  A₁₅ A₁₄ A₁₃ → 74LS138 C B A
  74LS138 Y₀~Y₃ → 4片6264的CS₁
  CS₂接+5V（始终有效）
```

## 第4题：8088寻址方式与MOV指令（综合题）

**原题**：8088CPU中，设(DS)=2000H, (BX)=0100H, (SI)=0002H, (20100H)=12H, (20101H)=34H, (20102H)=56H, (20103H)=78H, (21200H)=2AH, (21201H)=4CH, (21202H)=B7H, (21203H)=65H，试分别说明下列各条指令执行完后AX寄存器中的内容是多少?

### 逐题解答

**① MOV AX, 1200H**
```
寻址方式：立即寻址
过程：立即数1200H直接送入AX
结果：AX = 1200H
```

**② MOV AX, [1200H]**
```
寻址方式：直接寻址
EA = 1200H
物理地址 = DS×16 + EA = 20000H + 1200H = 21200H
(21200H)=2AH → AL（低字节）
(21201H)=4CH → AH（高字节）
结果：AX = 4C2AH
```

**③ MOV AX, [BX]**
```
寻址方式：寄存器间接寻址
EA = BX = 0100H
物理地址 = 20000H + 0100H = 20100H
(20100H)=12H → AL
(20101H)=34H → AH
结果：AX = 3412H
```

**④ MOV AX, 1100H[BX]**
```
寻址方式：基址寻址
EA = 1100H + BX = 1100H + 0100H = 1200H
物理地址 = 20000H + 1200H = 21200H（同②）
结果：AX = 4C2AH
```

**⑤ MOV AX, [BX][SI]**
```
寻址方式：基址加变址寻址
EA = BX + SI = 0100H + 0002H = 0102H
物理地址 = 20000H + 0102H = 20102H
(20102H)=56H → AL
(20103H)=78H → AH
结果：AX = 7856H
```

**⑥ MOV AX, 1100H[BX][SI]**
```
寻址方式：基址加变址带位移
EA = 1100H + BX + SI = 1100H + 0100H + 0002H = 1202H
物理地址 = 20000H + 1202H = 21202H
(21202H)=B7H → AL
(21203H)=65H → AH
结果：AX = 65B7H
```

**⑦ LEA AX, 1100H[BX][SI]**
```
指令：LEA（Load Effective Address）
注意：LEA不访问内存！只计算有效地址送目标寄存器
结果：AX = EA = 1100H + 0100H + 0002H = 1202H
```

## 第5题：编程题

**原题**：内存按字节编址，从50000H单元开始，顺序8K个单元存放着8位补码表示的定点纯整数。编程序统计该8K数据中负数的个数，并放在BX中。

### 解题思路

**分析**：
- 内存起始地址：50000H
- 数据长度：8K = 8192 = 2000H 个字节
- 每个数据：8位补码表示
- 判断负数：最高位为1（即 TEST AL, 80H 或 CMP AL, 0 / JL）
- 结果放在BX

### 汇编代码

```asm
; 方法一：用TEST指令判断符号位
      MOV  AX, 5000H      ; 段地址 = 5000H
      MOV  DS, AX          ; 设置数据段
      XOR  BX, BX          ; BX清零，用于统计负数个数
      MOV  CX, 2000H       ; 循环计数 = 8K = 2000H
      MOV  SI, 0           ; 偏移地址从0开始

AGAIN:
      MOV  AL, [SI]        ; 取一个字节
      TEST AL, 80H         ; 测试最高位（符号位）
      JZ   NEXT            ; ZF=1说明符号位=0（非负），跳转
      INC  BX              ; 是负数，BX加1
NEXT:
      INC  SI              ; 指向下一个数据
      LOOP AGAIN           ; CX-1, 若CX≠0继续循环
      ; 程序结束，BX中为负数个数
```

```asm
; 方法二：用CMP/JL判断（更直观）
      MOV  AX, 5000H
      MOV  DS, AX
      XOR  BX, BX
      MOV  CX, 2000H
      MOV  SI, 0

AGAIN:
      MOV  AL, [SI]
      CMP  AL, 0           ; 与0比较
      JGE  NEXT            ; ≥0则跳转（JL只对负数成立）
      INC  BX
NEXT:
      INC  SI
      LOOP AGAIN
```

**注意**：对于8位补码数，`CMP AL, 0` 后 `JL` 跳转的条件是 AL < 0（即最高位为1）。

## 第6题：微指令格式设计（设计题）

**原题**：某微程序控制器采用的微指令字长为24位。微命令生成部分由4个字段构成，各字段所包括的互斥微命令分别为5个、8个、14个和3个。另外控制产生后继（次）地址的条件有3种。试设计该微指令的格式，说明各个字段（包括次地址等字段）的划分方法，并指出控制存储器的最大容量为多少？

### 解答

**① 计算各字段位数**

| 字段 | 互斥微命令数 | +1(空操) | log₂向上取整 | 位数 |
|:----:|:-----------:|:--------:|:-----------:|:----:|
| 字段1 | 5 | 6 | ⌈log₂6⌉ | **3** |
| 字段2 | 8 | 9 | ⌈log₂9⌉ | **4** |
| 字段3 | 14 | 15 | ⌈log₂15⌉ | **4** |
| 字段4 | 3 | 4 | ⌈log₂4⌉ | **2** |

**② 操作控制字段总位数**
```
3 + 4 + 4 + 2 = 13位
```

**③ 顺序控制字段**
```
剩余 = 24 - 13 = 11位
条件字段：3种条件 → (3+1) → ⌈log₂4⌉ = 2位
下地址字段：11 - 2 = 9位
```

**④ 微指令格式**

```
|  字段1  |  字段2  |  字段3  |  字段4  |  条件  |  下地址  |
|  3位    |  4位    |  4位    |  2位    |  2位   |  9位     |
|←────── 操作控制部分 (13位) ──────→|←── 顺序控制 (11位) ──→|
```

各字段说明：
```
字段1（3位）：可编码6种状态，控制5个互斥微命令+空操作
字段2（4位）：可编码16种状态，控制8个互斥微命令+空操作
字段3（4位）：可编码16种状态，控制14个互斥微命令+空操作
字段4（2位）：可编码4种状态，控制3个互斥微命令+空操作
条件（2位）：选择产生后继地址的条件（4种选择：3种条件+无条件）
下地址（9位）：指定下一条微指令在控制存储器中的地址（0~511）
```

**⑤ 控制存储器容量**
```
下地址9位 → 最大可寻址 2⁹ = 512 个微单元
每单元 = 24位 = 3字节
CM最大容量 = 512 × 3B = 1536B = 1.5KB
```

## 第7题：微操作流程（综合题）

**原题**：某CPU构成的计算机框图如下。其內部总线及內部寄存器均为16位；主存储器按16位编址。采用数据通路描述方式、控制信号描述方式或两者混合的描述方式，写出在该计算机上，指令 OR [1500H],AX 的取指令、指令执行的微操作流程。(假设该指令由二个16位的字构成，主存中占二个地址)

### 解答

**指令含义**：`OR [1500H], AX` → 将内存1500H处的字与AX的内容按位或，结果写回内存1500H

#### 取指令阶段

```
T1: PC → MAR          ; 送指令第一字地址
    Read = 1

T2: M(MAR) → MDR      ; 从主存读出指令第一字
    PC + 1 → PC

T3: MDR → IR          ; 指令送IR译码

T4: PC → MAR          ; 指令占2个字，取第二字
    Read = 1

T5: M(MAR) → MDR      ; 读出指令第二字（操作数地址=1500H）
    PC + 1 → PC

T6: MDR → B           ; 将1500H暂存到B寄存器
```

#### 执行阶段

```
; 取[1500H]的内容
T7: B → MAR           ; 将操作数地址1500H送MAR
    Read = 1

T8: M(MAR) → MDR      ; 读出[1500H]的内容
    MDR → A           ; 第一个操作数送A寄存器

; 执行OR运算
T9: AX → B            ; 第二个操作数（AX内容）送B
    ALU_OP = OR       ; 执行按位或
    ALUout → MDR      ; 结果送MDR

; 写回内存
T10: Write = 1         ; 写使能
     MDR → M(MAR)     ; 结果写回[1500H]单元
```

## 第8题：触发逻辑表达式（简答/设计题）

**原题**：某计算机指令对应的微操作表如下所示，根据表可知 I→IND 的触发逻辑为：`I→IND = FE·T2·(ADD + SAT + LDA + JMP + BAN)`。请参照该形式，写出 M(MAR)→MDR 的触发逻辑表达式。

### 解题思路

`M(MAR)→MDR` 表示从主存读出一个字到MDR，这个微操作在以下情况下发生：
1. **取指令阶段**：每个指令都需要从主存取指令 → T2节拍
2. **执行阶段**：某些指令需要从主存读操作数

### 表达式

```
M(MAR)→MDR = FE·T2·(所有指令之和) + 执行阶段中需要读内存的指令
```

如果题目给的微操作表中，`M(MAR)→MDR` 出现情况为：
- 所有指令在取指 T2
- ADD、LDA、AND等指令在执行的某节拍（如T2）也需要读内存

则具体表达式为：
```
M(MAR)→MDR = FE·T2·(ADD+SAT+LDA+JMP+BAN+...) + EX·T2·(ADD+LDA+AND+...)
```

### 分析说明

本题的关键是理解触发逻辑表达式的结构：
```
微操作 = 节拍 × 需要该微操作的指令集合
```

其中 FE/EX 分别表示取指阶段和执行阶段，用于区分不同阶段的相同节拍。
